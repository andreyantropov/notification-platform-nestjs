# notification-platform

Событийно-ориентированная платформа уведомлений. Обеспечивает независимый прием, обогащение данных и стратегическую маршрутизацию по каналам доставки.

---

## Архитектура и документация

Подробное описание архитектуры, схемы взаимодействия сервисов и принятые технические решения (ADR) находятся в изолированной папке проекта.

**[Перейти к архитектурной документации](./docs/)**

Внутри документации вы найдете:

- Схемы топологии RabbitMQ (Exchanges, Queues, Routing Keys).
- Диаграммы последовательности обработки запроса.
- Контракты данных между микросервисами.

---

## Структура репозитория

```bash
├── apps/                 # Микросервисы платформы
│   ├── receive-service/  # Сервис приема, валидации и обогащения запросов
│   └── delivery-service/ # Сервис-воркер, отправляющий уведомления по стратегиям
├── docs/                 # Папка с архитектурой и схемами
├── infra/                # Конфигурации инфраструктуры
├── libs/                 # Переиспользуемые внутренние библиотеки (типы, логгер)
└── docker-compose.yml    # Инфраструктура для локальной разработки
```

## Быстрый старт (Локальный запуск)

### 1. Окружение

Убедитесь, что у вас установлены **Docker**, **Docker Compose** и **Node.js LTS**.

### 2. Запуск зависимостей (Инфраструктуры)

Поднимите локальный брокер RabbitMQ. Сами микросервисы будут запущены локально для удобного дебага.

```bash
docker compose up -d
```

### 3. Установка зависимостей и запуск сервисов

Установите пакеты и запустите оба микросервиса в режиме разработки (с поддержкой hot-reload):

```bash
pnpm install
pnpm run start:dev:receive
pnpm run start:dev:delivery
```
